# Factory Flow Manager

อยากให้สร้างfrontend เขียนโดยreact โดยจะมีระบบคลังสินค้าสำเร็จรูปและจัดส่งสินค้าและระบบจัดการข้อมูลผลิตภัณฑ์/สูตรการผลิต ซึ่งทั้งสองระบบนี้เป็นส่วนหนึ่งของระบบใหญ่คือระบบจัดการการผลิตในโรงงาน อยากให้design UI ตามที่เห็นในไฟล์เลย ในส่วนระบบอื่นๆในระบบจัดการการผลิตในโรงงานยังไม่ต้องใส่เข้ามา เอาแค่2ระบบให้ทำงานได้ ตาม featureนี้ที่อยู่ในไฟล์
